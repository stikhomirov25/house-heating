# Климат дома

1. При установке через HACS откройте меню ⋮ → «Пользовательские репозитории», добавьте URL GitHub-репозитория с типом «Интеграция», откройте «Климат дома», нажмите «Скачать» и перезапустите Home Assistant. Для ручной установки скопируйте папку `custom_components/house_heating` целиком в `/config/custom_components/` вашего Home Assistant. Перезапустите Home Assistant.
2. Откройте «Настройки → Устройства и службы → Добавить интеграцию» и выберите «Климат дома». В мастере выберите котёл и общий пол, затем задайте названия и устройства четырёх комнат первого этажа и шести комнат второго. Можно выбрать несколько датчиков и несколько радиаторов. Если у вас есть локальная карта устройств в JSON, вместо ручного заполнения выберите «Вставить карту устройств (JSON)». Для замены устройства откройте меню ⋮ интеграции → «Перенастроить». Перед заменой отключите выводимый из эксплуатации нагреватель. После изменения привязок подтвердите управление заданием температуры на термостате дома. До первого задания температуры всего дома контроллер только показывает показания. Перед запуском проверьте сущности из таблицы в «Инструменты разработчика → Состояния». Если другие правила уже управляют этими же выходами, их команды могут конфликтовать.
3. На панели с радиаторами нажмите «Редактировать → Добавить карточку → Вручную» и вставьте содержимое `card.yaml`. Карточка использует стандартные элементы Home Assistant. Если HA уже занял один из идентификаторов climate.house_heating_*, подставьте в карточку фактическое имя из реестра.
4. Задайте первую общую температуру на «Весь дом». Можно также вызвать climate.set_temperature. Дальше уставку можно менять на любом из 13 термостатов. Значения сохраняются при перезапуске.

Для расписания создайте автоматизацию с триггером «Время» и действием «Климат: задать температуру». Выберите climate.house_heating_floor1 и нужную температуру, затем добавьте второе действие для climate.house_heating_floor2. Для режима отъезда достаточно одного действия на climate.house_heating_home.

Пример одного действия в редакторе YAML:

```yaml
action: climate.set_temperature
target:
  entity_id: climate.house_heating_floor1
data:
  temperature: 19
```

Гистерезис задаётся в «Настройки → Устройства и службы → Климат дома → Настроить». Значение общее для всех комнат, от 0 до 5 °C с шагом 0,1 °C. По умолчанию 1 °C. После сохранения интеграция перезагружается и пересчитывает запросы, сохраняя уставки, активность управления и действующую ручную паузу. Следующий пример относится к гистерезису 1 °C. При уставке 26 °C остывшая комната начинает запрашивать тепло при 25 °C или ниже. Запрос снимается при 26 °C или выше. Между порогами сохраняется предыдущий запрос. Для кухни берётся среднее двух датчиков. Если доступен только один, используется его значение. Комната без доступных датчиков снимает свой запрос. Для дома и этажей фактическая температура и уставка считаются отдельно, каждая комната имеет равный вес. На карточках действие «Нагрев» обозначает запрос соответствующих комнат.

Общий пол первого этажа включается по запросу любой из четырёх комнат этого этажа. Полы ванной и санузла второго этажа получают команду heat (или heat_cool, если регулятор поддерживает его вместо heat), а после подтверждения режима — уставку регулятора 33 °C. При снятии запроса пол переключается в off. Уставка комнаты регулируется отдельно. Ограничения температуры пола задаются на самом регуляторе. Котёл получает команду включения при запросе любой из десяти комнат. При установке 19 °C новый запрос появляется при 18 °C или ниже. Уже начавшийся нагрев продолжается до 19 °C.

В таблице радиаторы представлены сущностями climate. Для открытия интеграция выбирает heat и максимальную поддерживаемую уставку головки, для закрытия — off, а у головок без off — минимальную уставку. Это приближение к двухпозиционному клапану: фактический ход штока, защиту от замерзания и реакцию на команды определяет сама головка. При вводе в эксплуатацию проверьте открытие и закрытие каждой модели. Для гарантированного задания положения нужны отдельные сущности привода, если модель их предоставляет.

При ручном переводе любого из трёх полов или котла из включённого состояния в off контроллер оставляет оборудование в текущем положении на 30 минут. Уставки в это время можно менять. После паузы контроллер пересчитает запросы по свежим показаниям в пределах 5 секунд. Отсчёт сохраняется при перезапуске. Home Assistant должен получить изменение состояния устройства. При потере контекста команды интеграция считает отчёт off в течение 30 секунд после своей команды выключения подтверждением этой команды. При отключённом Home Assistant устройства продолжают работать согласно собственным настройкам.
